### 📌 Project Overview
This lab focuses on adding a proper **Restaurant Menu Table** to the BiteBox website.  
The menu now displays food categories, items, prices, and availability using advanced table features like `rowspan` and `colspan`.

---

### ✨ What Was Added
- HTML Table for Restaurant Menu
- Table headers (`th`) and data cells (`td`)
- `rowspan` for category grouping (Pizza)
- `colspan` for weekend offer row
- Table caption
- Price and Availability columns
- Existing features retained (images, lists, navigation)

---

### 📄 Pages Included

| Page    | File           | Description                                      |
|---------|----------------|--------------------------------------------------|
| Home    | `index.html`   | Semantic structured home page                    |
| Menu    | `menu.html`    | Enhanced menu with table, images & lists         |
| About   | `about.html`   | About Us page                                    |
| Contact | `contact.html` | Contact information page                         |

---

### 🛠️ Skills Demonstrated
- HTML Tables (`table`, `tr`, `th`, `td`)
- `rowspan` and `colspan`
- Table caption
- Structured menu presentation
- Multi-page navigation
- Content organization

---

### 🚀 How to Run
1. Open the repository
2. Open `index.html` in any web browser
3. Go to the **Menu** page to see the table

> **Note:** Update image paths to relative paths (e.g. `assets/images/pizza.png`) so images work on GitHub.
